🎨 Visual Editor Svelte 5 - Exemple Local

📋 Instructions

  1. Builder le package: cd visual-editor-svelte && npm run build
  2. Servir ce fichier avec un serveur HTTP (ex: python3 -m http.server 8000)
  3. Ouvrir http://localhost:8000/examples/simple-html-example.html

Note: Vous devez avoir un serveur de preview qui répond aux requêtes POST sur /api/preview
